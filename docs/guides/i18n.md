# Internationalisierung (Version 0.1.0)

Unser Framework unterstützt Internationalisierung (i18n) insofern, dass für Sprachen welche von rechts nach links gelesen werden, wie zum Beispiel Arabisch, das Layout der Webseite ebenfalls von rechts nach links angeordnet wird.

Um Texte auf der Webseite zu übersetzen, muss jedoch trotzdem zuerst Django's internes i18n System aktiviert werden.

## Allgemeine Informationen zur Internationalisierung

Das i18n System von Django wird folgendermaßen aktiviert:

1. Die folgenden Einstellungen in der settings.py müssen aktiviert werden:

```python
USE_I18N = True
USE_L10N = True

MIDDLEWARE = [
    # ...
    'django.middleware.locale.LocaleMiddleware',
    # ...
]

# Liste aller Sprachen welche Unterstützt werden sollen (min. Deutsch und Englisch)
LANGUAGES = [
    ('de', 'Deutsch'),
    ('en', 'English'),
    # ...
]
```

2. Um Texte in Templates zu übersetzen, müssen die i18n-Tags in den Templates aktiviert werden:

```django
{% load i18n %}
```

## RTL-Unterstützung

Für Sprachen, die von rechts nach links geschrieben werden (wie Arabisch), bietet Insight UI vollständige RTL-Unterstützung:

1. Die Richtung wird automatisch basierend auf der aktiven Sprache erkannt
2. CSS-Layouts werden automatisch angepasst
3. Komponenten werden korrekt ausgerichtet

## Eigene Übersetzungen hinzufügen

1. Erstellen der entsprechenden .po-Datei für die jeweilige Sprache:

```bash
django-admin makemessages -l [locale]
```

2. Anschließend können in der .po-Datei direkt die Übersetzungen eingetragen werden, wir empfehlen aber [django-rosetta](https://pypi.org/project/django-rosetta/) zu verwenden.

3. Im letzten Schritt müssen die Übersetzungen kompiliert werden (also übersetzt ^^):

**_Info_**: Sollte _django-rosetta_ verwendet werden, muss Schritt drei nicht ausgeführt werden.

```bash
django-admin compilemessages
```

## Beispiel: Mehrsprachige Komponente

```django
{% load i18n insight_tags %}

{% alert message=_("Willkommen bei unserer Anwendung!") type="info" %}

<h1>{% trans "Über uns" %}</h1>
<p>
  {% blocktrans %}
    Wir sind ein Unternehmen, das sich auf die Entwicklung von Webanwendungen spezialisiert hat.
  {% endblocktrans %}
</p>
```
