# Phrasen / Formulierungen (Version 0.1.0)

Dieser Guide behandelt das Thema der Phrasen, welche immer wieder gebraucht werden. Dabei handelt es sich um meist kurze und generische Sätze, welche nicht im konkreten Zusammenhang mit dem Thema der Anwendung stehen. Damit sind zum Beispiel Formulierungen für ein Dialog zum Löschen einer Datei gemeint oder Bestätigungstexte.

Auch hier geht es in erster Linie darum, wildwuchs zu minimieren.
