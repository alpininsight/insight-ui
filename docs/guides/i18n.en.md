# Internationalisation (Version 0.1.0)

Insight UI supports internationalisation (i18n) by adapting layouts for right-to-left (RTL) languages and exposing translation hooks throughout the templates. Use Django's built-in localisation features to provide translations.

## Enabling i18n in Django

1. Activate the i18n settings in `settings.py`:

```python
USE_I18N = True
USE_L10N = True

MIDDLEWARE = [
    # ...
    "django.middleware.locale.LocaleMiddleware",
    # ...
]

LANGUAGES = [
    ("de", "Deutsch"),
    ("en", "English"),
    # add further locales as needed
]
```

2. Load the `i18n` template tags whenever you translate strings:

```django
{% load i18n %}
```

## Language Switcher

The Insight UI navbar includes a language selector out of the box. If you do not need it, set `show_language_selector=False` in your navbar configuration.

## RTL Support

When a right-to-left language is active, the layout mirrors automatically:

1. The direction attribute (`dir="rtl"`) is applied to the `<html>` element.
2. Tailwind tokens adjust spacing and positioning.
3. Components respect mirrored padding/margins.

## Adding Translations

1. Extract messages:

```bash
django-admin makemessages -l <locale>
```

2. Translate strings in the generated `.po` files. Tools such as [django-rosetta](https://pypi.org/project/django-rosetta/) can streamline this process.

3. Compile translations:

```bash
django-admin compilemessages
```

With `django-rosetta`, the compilation step is performed automatically when saving translations.

## Example

```django
{% load i18n insight_tags %}

{% alert message=_("Welcome to our application!") type="info" %}

<h1>{% trans "About us" %}</h1>
<p>
  {% blocktrans %}
    We build web applications tailored to your needs.
  {% endblocktrans %}
</p>
```
