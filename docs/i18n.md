# Internationalization (i18n)

Insight UI supports internationalization including right-to-left (RTL) languages like Arabic and Hebrew.

## Django i18n Setup

Enable Django's i18n system in `settings.py`:

```python
USE_I18N = True
USE_L10N = True

MIDDLEWARE = [
    # ...
    'django.middleware.locale.LocaleMiddleware',
    # ...
]

LANGUAGES = [
    ('de', 'Deutsch'),
    ('en', 'English'),
    ('ar', 'العربية'),  # RTL language
]

LOCALE_PATHS = [
    BASE_DIR / 'locale',
]
```

Load i18n tags in your templates:

```django
{% load i18n %}
```

## RTL Support

Insight UI provides full RTL support for languages like Arabic and Hebrew.

### How RTL Detection Works

The base template automatically sets the `dir` attribute based on Django's `LANGUAGE_BIDI` variable:

```html
<html lang="{{ LANGUAGE_CODE }}" dir="{% if LANGUAGE_BIDI %}rtl{% else %}ltr{% endif %}">
```

Django determines `LANGUAGE_BIDI` based on the active language. Languages like Arabic (`ar`), Hebrew (`he`), Persian (`fa`), and Urdu (`ur`) are automatically recognized as RTL.

### How Components Handle RTL

Components use Tailwind's `rtl:` and `ltr:` prefixes to adjust layouts:

```html
<!-- Sidebar positioning -->
<div class="ltr:left-0 rtl:right-0">

<!-- Carousel navigation -->
<button class="ltr:left-4 rtl:right-4">

<!-- Flex direction -->
<div class="flex rtl:flex-row-reverse">
```

This means layouts automatically mirror when the language direction changes.

## Adding a New Language

### Step 1: Add to Settings

```python
LANGUAGES = [
    ('de', 'Deutsch'),
    ('en', 'English'),
    ('fr', 'Français'),  # New language
]
```

### Step 2: Create Translation Files

```bash
# Create locale directory
mkdir -p locale/fr/LC_MESSAGES

# Generate .po file for the new language
uv run python manage.py makemessages -l fr

# Or use the Makefile
make messages
```

### Step 3: Translate Strings

Edit `locale/fr/LC_MESSAGES/django.po` and add translations:

```po
#: documentation/component_details/description_context.py:42
msgid "A button triggers an action when clicked."
msgstr "Un bouton déclenche une action lorsqu'il est cliqué."
```

Or use [django-rosetta](https://pypi.org/project/django-rosetta/) for a web-based translation interface.

### Step 4: Compile Translations

```bash
uv run python manage.py compilemessages

# Or use the Makefile
make compile-messages
```

### Step 5: Regenerate Search Index

If using the documentation search:

```bash
uv run python manage.py build_search_index --locale fr
```

## Translating Component Strings

### In Python Code

Use `gettext` (`_`) for translatable strings:

```python
from django.utils.translation import gettext as _

@register_component(Component.BUTTON)
def get_button_description() -> dict:
    return {
        "description": _("A button triggers an action when clicked.")
    }
```

### In Templates

Use `{% trans %}` for simple strings:

```django
{% load i18n insight_tags %}

<h1>{% trans "Welcome" %}</h1>
```

Use `{% blocktrans %}` for strings with variables:

```django
{% blocktrans with name=user.name %}
    Hello, {{ name }}!
{% endblocktrans %}
```

### In Component Tags

Translatable strings can be passed directly:

```django
{% alert message=_("Operation successful!") type="success" %}
```

## Language Switcher

Insight UI includes a language switcher in the navbar. It can be enabled/disabled in your navbar configuration.

## Testing Translations

### Verify Translation Coverage

```bash
# Check for missing translations
uv run python manage.py makemessages -l de --no-obsolete

# Look for empty msgstr entries in .po files
grep -n 'msgstr ""' locale/de/LC_MESSAGES/django.po
```

### Test RTL Layout

1. Add an RTL language to your settings:
   ```python
   LANGUAGES = [
       ('en', 'English'),
       ('ar', 'العربية'),
   ]
   ```

2. Switch to Arabic in the language switcher

3. Verify:
   - Text flows right-to-left
   - Sidebars appear on the correct side
   - Navigation elements are mirrored
   - Icons (like arrows) are flipped appropriately

### Common RTL Issues

| Issue | Solution |
|-------|----------|
| Icons not flipping | Use `rtl:rotate-180` class |
| Spacing not mirroring | Use `start`/`end` instead of `left`/`right` |
| Flex direction wrong | Add `rtl:flex-row-reverse` |
