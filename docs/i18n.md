# Internationalization (i18n)

Our framework supports internationalization in that for languages that are read from right to left, such as Arabic, the layout of the website is also arranged from right to left.

However, in order to translate texts on the website, Django's internal i18n system must first be activated.

## General information about internationalization

Django's i18n system is enabled as follows:

1. The following settings in settings.py must be enabled:

```python
USE_I18N = True
USE_L10N = True

MIDDLEWARE = [
    # ...
    'django.middleware.locale.LocaleMiddleware',
    # ...
]

# List of all languages to be supported
LANGUAGES = [
    ('de', 'Deutsch'),
    ('en', 'English'),
    # ...
]
```

2. To translate texts in templates, the i18n tags must be activated in the templates:

```django
{% load i18n %}
```

## Language switch

Insight UI offers an integrated language switch in the navigation bar (this can also be disabled).

## RTL support

For languages that are written from right to left (such as Arabic), Insight UI offers full RTL support:

1. The direction is automatically detected based on the active language
2. CSS layouts are automatically adjusted
3. Components are aligned correctly

## Add your own translations

1. Create the corresponding .po file for the respective language:

```bash
django-admin makemessages -l [locale]
```

2. The translations can then be entered directly into the .po file, but we recommend using [django-rosetta](https://pypi.org/project/django-rosetta/).

3. In the final step, the translations must be compiled (i.e., translated ^^):

```bash
django-admin compilemessages
```

**_Info_**: When _django-rosetta_ is used, step three does not need to be performed.

## Example: Multilingual component

```django
{% load i18n insight_tags %}

{% alert message=_("Willkommen bei unserer Anwendung!") type="info" %}

<h1>{% trans "Über uns" %}</h1>
<p>
  {% blocktrans %}
    Wir sind ein Unternehmen, das sich auf die Entwicklung von Webanwendungen spezialisiert hat.
  {% endblocktrans %}
</p>
```
