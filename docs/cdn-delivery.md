# Package CDN Contract

The public contract is documented in [Static assets](static-assets.md): readable
package files, generated minified variants, relative imports and optional
host-owned CDN settings. The [verification manifest](../insight_ui/cdn_manifest.json)
is package-owned; it is a verification subset, not the full publication list.

Local development and package usage do not require CDN access. Upload tooling,
credentials and an organization's release/deployment procedures are not part of
this contributor guide. The separate reference application's assets are not
package assets and must not be added to the package manifest.
