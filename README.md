# CLA signatures

This branch is maintained by the CLA Assistant workflow
(`.github/workflows/cla.yml`). It exists only to hold the record of who has
signed the Insight UI Contributor Licence Agreement.

- Signatures live in `signatures/version1/cla.json`.
- The file is written by the bot. Do not edit it by hand.
- This branch has no shared history with `develop` and must never be merged
  into it.

The agreement itself is `CLA.md` on `develop`. Questions:
contact@alpininsight.com
