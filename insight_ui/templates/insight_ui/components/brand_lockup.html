{% load i18n %} {% comment %} Brand lockup: a wing logo + two-tone wordmark. `variant` picks the wing mark — wing-slice (company logo, default), dual-wing (dev environment), or wing-arc (candidate environments). Apps typically select it by deployment lane. See alpininsight/insight-brand#123. Colours are inline `var(--color-insight-*)` references on purpose: the SVG fills are presentation attributes (not Tailwind), and using the same tokens for the wordmark keeps the lockup theme-following without depending on a `text-insight-secondary` utility that isn't always compiled. A brand-themed app that overrides the tokens (Navy/Orange) gets brand colours with zero extra markup. Layout: a single logo placement (no per-position duplication). When logo_position == "end", the wing gets `order: 2` so the wordmark sits left and the logo is pushed to the far edge via justify-between; inline `order` avoids depending on a Tailwind order-* utility. Wordmark text is a brand name and is intentionally not wrapped in {% trans %}. The logo is decorative (aria-hidden) because the wordmark text is already read by assistive tech. {% endcomment %}
