{% blocktrans trimmed %} Insight UI uses type literals to ensure type safety and provide autocompletion in your IDE. These types define the allowed values for component parameters like sizes, colors, and positions. {% endblocktrans %}

{% blocktrans trimmed %} All types are defined in insight_ui.configs.types and can be imported for type annotations in your own code. {% endblocktrans %}

{% trans "Usage Example" %}

{# fmt:off #} from insight_ui.configs.types import Size, ColorType # Type hints for function parameters def create_button(size: Size = "m", color: ColorType = "primary"): ... # Direct value usage in templates {% templatetag openblock %} button label="Click" size="l" type="secondary" {% templatetag closeblock %} {# fmt:on #}

{% trans "Validation" %}

{% blocktrans trimmed %} Each type has a corresponding validation function that raises a ValueError if an invalid value is passed. These validators are automatically called in config dataclasses during initialization. {% endblocktrans %}

from insight_ui.configs.types import validate_size, validate_color_type # Raises ValueError for invalid values validate_size("invalid") # ValueError: Invalid size 'invalid'. ... validate_color_type("primary") # OK # Validators support custom field names for error messages validate_size("xl", field_name="icon_size") # Uses 'icon_size' in error message
