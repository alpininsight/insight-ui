Get started

Installation

Insight-UI wird wie gewohnt über ein Python Paketmanager wie pip oder uv installiert.

{# fmt:off #} uv add insight-ui # oder die Git-Quelle verwenden uv add "git+https://github.com/alpininsight/insight-ui@main" {# fmt:on #}

Schnellstart

Schritt Nr. 1 ist es insight-ui zu den INSTALLED_APPS in der settings.py hinzufügen:

{# fmt:off #} INSTALLED_APPS = [ # ... 'insight_ui', # ... ] {# fmt:on #}

Anschließend kann der Entwicklungsserver gestartet werden python manage.py runserver

Base Template

Um alle Funktionen von Insight-UI verwenden zu können, muss unser Base Template eingebunden werden.

{# fmt:off #} {% extends "insight_ui/base.html" %} {# fmt:on #}

Damit die Konfiguration von Insight-UI geladen werden kann, müssen die entsprechende Variablen in den Kontext geladen werden. Dazu muss die Konfiguration in jeder View, welche das Base Template verwendet, übergeben werden. Siehe auch Konfiguration anpassen.

{# fmt:off #} from insight_ui import config def my_view(request: HttpRequest) -> HttpResponse: """Render my new page.""" context = config.get_config() return render(request, "insight_ui/docs/customization.html", context) {# fmt:on #}
