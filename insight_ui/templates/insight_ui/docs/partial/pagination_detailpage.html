Mit der pagination Komponente lässt sich eine Liste auf mehrere Seiten aufteilen, welche mittels der durch diese Komponente dargestellte Pagination am Ende der Liste gewechselt werden kann. Dies ist praktisch für große Datenmengen und bietet eine alternative zur infinite_scroll Komponente.

{% include "insight_ui/docs/demo_container.html" %}

{% trans "Verwendung" %}

{% blocktrans with pagination='{% pagination %}'|safe %} Die Komponente wird über das {{ pagination }} Tag eingebunden. {% endblocktrans %}

{# fmt:off #} {% load insight_tags %} <div id="list-container"> {% pagination with current_page=start_page surrounding_pages=surrounding_pages %} </div> {# fmt:on #}

{% trans "Parameter" %}

{% include "insight_ui/components/parameter_table.html" with rows=main_params %}

Ein von Django erzeugtes Pagination-Objekt der aktuellen Seite.
