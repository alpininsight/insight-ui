Insight UI Pagination

Mit der paginated_list Komponente lässt sich eine Liste auf mehrere Seiten aufteilen, welche mittels der durch diese Komponente dargestellte Pagination am Ende der Liste gewechselt werden kann. Dies ist praktisch für große Datenmengen und bietet eine alternative zur infinite_scroll Komponente.

{% include "insight_ui/docs/demo_container.html" %}

{% trans "Verwendung" %}

{# fmt:off #} {% load insight_tags %} <div id="list-container"> {% paginated_list with current_page=start_page surrounding_pages=surrounding_pages %} </div> {# fmt:on #}

{% trans "Parameter" %}

  • current_page (Page): Ein von Django erzeugtes Pagination-Objekt der aktuellen Seite.
  • surrounding_pages (list): Eine liste der benachbarten Seiten.
