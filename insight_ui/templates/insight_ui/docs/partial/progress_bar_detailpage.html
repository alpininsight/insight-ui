Insight UI Progress-Bar

Info: Diese Komponente befindet sich noch in Bearbeitung!

Die progress_bar Komponente wird dafür verwendet dem Nutzer den Fortschritt eines im Hintergrund laufenden Prozesses visuell darzustellen. Ein gängiges Szenario für solche Komponenten sind zum Beispiel Downloads.

Für eine Fortschrittsanzeige wo der Fortschritt durch aktives Zutun des Nutzers entsteht, eignet sich unsere {% trans "Step Bar" %} Komponente.
