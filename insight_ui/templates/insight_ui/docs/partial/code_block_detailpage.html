Insight UI Code Block

{% trans 'Diese Komponente bietet die Möglichkeit, Quellcode mit Syntax-Highlighting darzustellen. Darüber hinaus gibt es Möglichkeit, den dargestellten Quellcode, über einen Button in den Zwischenspeicher zu kopieren. Das Syntax-Highlighting umfasst so ziemlich alle gängigen und auch die meisten nicht sehr geläufigen Programmiersprachen.' %}

function greet(name) { return `Hello, ${name}!`; }

{% trans "Verwendung" %}

{% trans "Diese Komponente wird ohne ein Template einzubinden, verwendet. Es muss lediglich ein HTML-Tag vorzugsweise ein `

` eingefügt werden. Dieses braucht eine Eindeutige `id`, diese ist für das Kopieren wichtig. Zum anderen muss das Tag den _data-Attribute_ ` data-insight-code-block` besitzen. Der Wert des _data-Attributes_ ist die gewünschte Programmiersprache. Innerhalb des Tags befindet sich dann ausschließlich der darzustellende Quellcode." %}

<div id="code" data-insight-code-block="javascript"> function greet(name) { return `Hello, ${name}!`; } </div>

Info: {% blocktrans with copy='Copy'|safe %} Beim klick auf den {{ copy }} Button wird der Quellcode hervorgehoben und gleichzeitig in den Zwischenspeicher kopiert. Ein erneutes kopieren ist nicht notwendig. {% endblocktrans %}
