Insight UI Code Block

{% trans 'Diese Komponente bietet die Möglichkeit, Quellcode mit Syntax-Highlighting darzustellen. Darüber hinaus gibt es Möglichkeit, den dargestellten Quellcode, über einen Button in den Zwischenspeicher zu kopieren. Das Syntax-Highlighting umfasst so ziemlich alle gängigen und auch die meisten nicht sehr geläufigen Programmiersprachen.' %}

{% include "insight_ui/docs/demo_container.html" %}

{% trans "Verwendung" %}

{% blocktrans with div='<div>' tag_id='Tag-ID'|safe data_attr='data-Attribute'|safe data_attr_value='data-insight-code-block'|safe %} Diese Komponente wird ohne ein Template einzubinden, verwendet. Es muss lediglich ein HTML-Tag vorzugsweise ein {{ div }} eingefügt werden. Dieses braucht eine Eindeutige {{ tag_id }}, diese ist für das Kopieren wichtig. Zum anderen muss das Tag den {{ data_attr }} {{ data_attr_value }} besitzen. Der Wert des {{ data_attr }} ist die gewünschte Programmiersprache. Innerhalb des Tags befindet sich dann ausschließlich der darzustellende Quellcode. {% endblocktrans %}

{# fmt:off #} <div id="code" data-insight-code-block="javascript"> function greet(name) { return `Hello, ${name}!`; } </div> {# fmt:on #}

Info: {% blocktrans with copy='Copy'|safe %} Beim klick auf den {{ copy }} Button wird der Quellcode hervorgehoben und gleichzeitig in den Zwischenspeicher kopiert. Ein erneutes kopieren ist nicht notwendig. {% endblocktrans %}
