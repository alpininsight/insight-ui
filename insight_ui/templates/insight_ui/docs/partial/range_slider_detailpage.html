Mit der slider-Komponente kann ein Range-Slider in das Frontend eingebaut werden, mit welchem sich ein Wert innerhalb eines begrenzten Intervall auswählen lässt.

{% include "insight_ui/docs/demo_container.html" %}

{% trans "Verwendung" %}

{% blocktrans with range_slider='{% range_slider %}'|safe %} Die Komponente wird über das {{ range_slider }} Tag eingebunden. {% endblocktrans %}

{% load insight-tags %} {% slider tag_id="cpu-cores" name="cpu_core_count" value=4 minimum=2 maximum=8 step_size=2 disabled=False label="Choose amount of CPU-Cores:" items=labels %} <!-- or --> {% slider config=slider_config %}

{% trans "Accessability" %}

  • Das <label> und der dazugehörige <input> sind mit for / id miteinander verknüpft.
  • Die Komponente unterstützt die Navigation über die Tastatur mittels der Pfeiltasten (hoch/runter, rechts/links).
