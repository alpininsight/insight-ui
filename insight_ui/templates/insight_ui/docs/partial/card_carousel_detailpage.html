{% trans "Custom content" %}

Um das Karussell mit eigenen Inhalt füllen zu können, muss zuerst ein neues Template erstellt werden, welches das Karussell Template erweitert. Anschließend muss der Block {% block carousel_content %} definiert werden und darin kann der Inhalt komplett frei definiert werden.

Info: {% blocktrans with bold_text='show_login'|safe %} Das Basis-Template des Karussells iteriert bereits durch die gegebenen Daten, daher ist es nicht notwendig, in dem eigenen Template nochmal durch die Daten zu iterieren. {% endblocktrans %}

{# fmt:off #} {% extends "insight_ui/components/carousel.html" %} {% block carousel_content %} <div> <h2>{{ item.titel }}</h2> <span>{{ item.subtitel }}</span> <p>{{ item.content }}</p> </div> {% endblock carousel_content %} {# fmt:on #}

Das neue Karussell wird bis auf den Pfad des Templates, genauso eingebunden wie bisher. Für carousel_items können nun die Daten mit der entsprechenden Struktur übergeben werden.
