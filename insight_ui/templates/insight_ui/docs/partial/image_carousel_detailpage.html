Insight UI Image Carousel

Die image_carousel Komponente ist eine auf die Darstellung von Bildern angepasste Variante der carousel Komponente.

Info: Diese Dokumentation bezieht sich nur auf das Bilder-Karussell. Für weitere Informationen zu dem Karussell allgemein, siehe {% trans "Karussell" %}.

{% include "insight_ui/docs/demo_container.html" %}

{% trans "Verwendung" %}

{% include "insight_ui/components/carousels/image_carousel.html" with carousel_items=image_carousel_items show_dots=True show_index=True slides_count=range_total_slides items_per_slide=1 %}

{% trans "Parameter" %}

  • carousel_items (list): Bilder welche innerhalb des Karussell angezeigt werden sollen.
  • show_index (bool): True wenn in der unteren rechten Ecke die aktuelle Seite angezeigt werden soll.
  • show_dots (bool): True wenn unter dem Karussell-Inhalt eine einfache Pagination angezeigt werden soll.
  • autoplay (bool): True wenn das Karussell von alleine durch den Inhalt iterieren soll.
  • slides_count (range): Die Anzahl der Seiten.
  • items_per_slide (int): Die Anzahl an Objekten pro Seite.

{% trans "Customization" %}

Das Basisdesign der Carousel Komponente befindet sich in dieser Datei: insight_ui/templates/insight_ui/components/carousel.html. Das Design des Image-Carousel in dieser insight_ui/templates/insight_ui/components/carousels/image_carousel.html.

Das Design kann am einfachsten angepasst werden, indem eine Kopie der Datei in den folgenden Pfad templates/insight_ui/components/ vom Projektverzeichnis aus gesehen, abgelegt wird. Anschließend wird immer dieses Template anstelle des Originals verwendet werden.
