Insight UI Footer

{% trans 'Ein einfacher Footer bestehend aus drei Spalten mit anpassbaren Inhalt. Der Footer ist ein wichtiger Bestandteil einer jeden Webseite, er dient jedoch nicht nur dazu, die Webseite optisch abzuschließen. Er enthält i.d.R. mindestens eine Verlinkung zum Impressum und der Datenschutzerklärung. Oft befindet sich im Footer noch einmal eine Navigation zu den wichtigsten Seiten der Webseite und eine Copyright Angabe.' %}

{% include "insight_ui/docs/demo_container.html" %}

{% trans "Verwendung" %}

{% blocktrans with footer='{% footer %}'|safe %} Der Footer wird über das {{ footer }} Tag eingebunden. Das Base-Template verfügt über einen, für den Footer vorgesehenen Block. Damit der Footer auch garantiert immer am Ende der Webseite erscheint, sollte dieser in vorgesehenen Block gepackt werden. {% endblocktrans %}
