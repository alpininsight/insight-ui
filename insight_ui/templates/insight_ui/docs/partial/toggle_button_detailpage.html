Insight UI Toggle Button

Mit der toggle Komponente lässt sich ein Toggle-Button einbauen. Dieser funktioniert im Grunde wie eine einzelne Checkbox.

{% include "insight_ui/docs/demo_container.html" %}

{% trans "Verwendung" %}

{% blocktrans with toggle_button='{% toggle_button %}'|safe %} Die Komponente wird über das {{ toggle_button }} Tag eingebunden. {% endblocktrans %}

{% load insight-tags %} {% toggle tag_id="theme-toggle" name="toggle_theme" value="toggle_theme" checked=False disabled=False label="Dark" method="changeTheme" switch=True %} <!-- or --> {% toggle config=toggle_config method="changeTheme" %}

{% trans "Parameter" %}

{% include "insight_ui/components/parameter_table.html" with rows=main_params %}

config (dict[str, Any])

Eine alternative Konfiguration mit Keys entsprechend den vorherigen Parametern.

{# fmt:off #} { "tag_id": "theme-toggle", "name": "toggle_theme", "value": "toggle_theme", "checked": False, "disabled": False, "label": "Dark", "switch": True, } {# fmt:on #}
