Insight UI Bullet Point List

Die bullet_point_list Komponente stellt eine Liste dar, welche mit deutlichen Bullet und Linien welche diese Verbinden dargestellt wird. Diese Liste ist vor allem für chronologische Listen gedacht, kann aber auch für ungeordnete Listen verwendet werden.
