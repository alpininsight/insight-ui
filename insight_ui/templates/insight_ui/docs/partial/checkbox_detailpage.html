Insight UI Checkbox

Mit der checkbox Komponente lassen sich einzelne Checkbox-Elemente einbauen. Für eine Gruppe von miteinander Verbundenen Checkbox-Elementen siehe Checkbox-Group .

{% include "insight_ui/docs/demo_container.html" %}

{% trans "Verwendung" %}

{% load insight_tags %} {% checkbox tag_id="agb-box" name="accept_agb" value="accept_agb" checked=False disabled=False label="Accept AGBs" %} # or {% checkbox config=checkbox_config %}

{% trans "Parameter" %}

  • tag_id (str): Eine optionale, eindeutige ID für JavaScript.
  • name (str): Wird für eine <form> benötigt, als Name des Request-Parameters.
  • value (str): Der Wert der Checkbox (Das ist nicht der Zustand, siehe dafür 'checked').
  • label (str): Ein Label-Text welcher über der Checkbox angezeigt wird.
  • checked (bool): True, wenn die Checkbox ausgewählt sein soll, andernfalls False.
  • disabled (bool): True, wenn die Checkbox deaktiviert sein soll, andernfalls False.
  • config (dict[str, Any]): Eine alternative Konfiguration mit Keys entsprechend den vorherigen Parametern.

config dict[str, Any]

{% trans "Eine alternative Konfiguration mit Keys entsprechend den vorherigen Parametern." %}

{# fmt:off #} { "id": "agb-box", "name": "accept_agb", "value": "accept_agb", "checked": False, "disabled": False, "label": "Accept AGBs", } {# fmt:on #}

{% trans "Accessability" %}

  • Das <label> und der dazugehörige <input> sind mit for / id miteinander verknüpft.
