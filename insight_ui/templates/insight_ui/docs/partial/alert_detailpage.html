Insight UI Alert

{% trans 'Die Alert-Komponente bietet eine Möglichkeit, Benutzern wichtige Informationen, Warnungen oder Erfolgsmeldungen anzuzeigen.' %}

{% include "insight_ui/docs/demo_container.html" %}

{% trans "Verwendung" %}

{% load insight_tags %} {% alert message="Ihre Änderungen wurden gespeichert." type="success" dismissible=True %}

{% trans "Parameter" %}

  • message (str): {% trans "Die Hauptnachricht der Benachrichtigung" %}
  • type (str): {% trans "Der Typ der Benachrichtigung. Mögliche Werte:" %} info success warning error
  • dismissible (bool): {% blocktrans with true='True'|safe %}{{ true }} wenn die Benachrichtigung schließbar sein soll. {% endblocktrans %}

{% trans "Customization" %}

Das Design der Alert Komponente befindet sich in dieser Datei: insight_ui/templates/insight_ui/components/alert.html.

Das Design kann am einfachsten angepasst werden, indem eine Kopie der Datei in den folgenden Pfad templates/insight_ui/components/ vom Projektverzeichnis aus gesehen, abgelegt wird. Anschließend wird immer dieses Template anstelle des Originals verwendet werden.

{% trans "Accessability" %}

  • Die Alert-Box besitzt das Attribute role="alert" für die Unterstützung eines Screenreader.
  • Der Button zum Schließen ist mit der Tastatur ansteuerbar und besitzt ein entsprechendes aria-label.
