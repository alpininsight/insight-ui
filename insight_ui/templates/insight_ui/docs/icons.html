{% trans "Adding Custom Icons" %}

{% blocktrans trimmed %} You can add your own icons using the compile_icons management command. This command generates a new icons.html template by merging your custom icons with the bundled icons. Custom icons override bundled icons with the same name. {% endblocktrans %}

{% trans "Basic Usage" %}

# From a directory of SVG files python manage.py compile_icons --dir path/to/icons/ # From an SVG sprite sheet python manage.py compile_icons --sprite path/to/sprite.svg # Combine both sources python manage.py compile_icons --dir path/to/icons/ --sprite path/to/sprite.svg

{% trans "Options" %}

  • --dir – {% trans "Directory containing individual SVG files" %}
  • --sprite – {% trans "Path to an SVG sprite sheet file (extracts <symbol> elements)" %}
  • --output – {% trans "Custom output path (default: templates/insight_ui/components/icons.html)" %}
  • --list-bundled – {% trans "List all bundled icon names and exit" %}

{% trans "Icon Naming" %}

{% blocktrans trimmed %} Icon names are derived from filenames (for directories) or symbol IDs (for sprites). Names are normalized: converted to lowercase, underscores become hyphens, and common prefixes like icon- or ic_ are removed. {% endblocktrans %}

my_custom_icon.svg → my-custom-icon Icon-ArrowLeft.svg → arrowleft ic_home.svg → home

{% trans "Example: Override a Bundled Icon" %}

{% blocktrans trimmed %} To replace the bundled home icon with your own version, create a file named home.svg in your icons directory: {% endblocktrans %}

python manage.py compile_icons --dir my_project/icons/ # Output: Total icons: 287 (1 custom, 287 bundled)
