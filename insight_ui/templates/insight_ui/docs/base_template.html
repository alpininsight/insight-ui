{% trans "Usage" %}

Das Base-Template kann ganz einfach verwendet werden, indem ein neues Template dieses erweitert. Dazu muss am Anfang des neuen Templates das {% extends %} Tag von Django verwendet werden.

{% extends "insight_ui/base.html" %}

<head>

Im Head werden alle benötigten JavaScript Bibliotheken verlinkt, sowie die SEO und das Favicon definiert.

  • {% block title %}

    Definiert den Title der Seite, welcher u.a. oben im Browser-Tab angezeigt wird.

  • {% block extra_head %}

    Zum Einbinden weiterer JavaScript Libraries.

Info: {% blocktrans with bold_text='INSIGHT_UI'|safe file='settings.py'|safe %} Das Favicon, die SEO Angaben, sowie weitere Meta-Information können über die {{ bold_text }} Einstellungen in der {{ file }} angepasst werden. {% endblocktrans %}

<body>

Der Body stellt ein, aus mehreren Blöcken bestehendes Grundgerüst für den Inhalt bereit. Jeder Block ist für einen bestimmten Zweck vorgesehen und sorgt dafür, dass das layout zusammen passt. Das Grundgerüst besteht aus den folgenden Blöcken:

  • {% block background_image %}

    Dieser Block kann verwendet werden, um etwas hinter allen anderen Blöcken anzuzeigen.

  • {% block navbar %}

    Der Block ist für die Navbar vorgesehen.

  • {% block drawers %}

    Dieser Block ist für ausklappbare Sidebars vorgesehen.

  • {% block sidebar_left %}

    Dieser Block befindet sich als erstes (links) im Hauptbereich und ist daher für die linke Sidebar vorgesehen.

  • {% block sidebar_right %}

    Dieser Block befindet sich als letztes (rechts) im Hauptbereich und ist daher für die rechte Sidebar vorgesehen.

  • {% block content %}

    Dieser Block befindet sich zwischen den Sidebar Blöcken und ist für den Hauptinhalt vorgesehen.

  • {% block footer %}

    Der Block ist für den Footer vorgesehen und wird nach dem Hauptbereich angezeigt.

  • {% block extra_scripts %}

    Zum Einbinden weiterer JavaScript Libraries.

Info: {% blocktrans with block_title='{% block title %}'|safe block_content='{% block content %}'|safe %} Diese Blöcke müssen nicht zwangsläufig verwendet werden, allerdings ist es empfehlenswert, da sich ein paar Strukturelle Gegebenheiten mit sich bringen. Theoretisch könnte aber auch alles in den {{ block_title }}. Es können bei Bedarf auch weitere JavaScript Bibliotheken verlinkt werden, durch den {{ block_content }} gepackt werden. {% endblocktrans %}

{% block background_image %}

Dieser Block befindet sich sozusagen hinter dem Eigentlichen Inhalt und kann dazu verwendet werden, ein Hintergrundbild einzubinden, welches fixiert ist, also sich bei scrollen mitbewegt.

{# fmt:off #} {% block background_image %} <img src="{% static "img/my_bg_image.png" %}" alt="My awesome background image." class="fixed left-1/4 -z-10 w-full h-dvh object-cover opacity-25"> {% endblock background_image %} {# fmt:on #}

{% block navbar %}

Die Navigationsleiste hat einen eigenen Bereich. Dieser ist vor dem restlichen Inhalt definiert, wodurch dieser immer als ersten auf der Seite auftaucht.

{# fmt:off #} {% load insight_tags %} {% block navbar %} {% navbar config=nav_config user=user user_dropdown_links=user_dropdown_links show_login=True search_query=search_query %} {% endblock navbar %} {# fmt:on #}
Für weitere Information über die Komponente, siehe {% trans "navbar" %} .

{% block drawers %}

In diesem Block können sog. Drawer eingebettet werden. Drawer sind ein- und ausklappbare Sidebars und liegen gewöhnlich über dem Inhalt. Daher haben sie ihren eigenen Block, damit sie nicht mit dem restlichen Layout in Konflikt geraten.

{# fmt:off #} {% load insight_tags %} {% block drawers %} {% sidebar sidebar_data=left_sidebar side="left" static=False %} {% endblock drawers %} {# fmt:on #}
Für weitere Information über die Komponente, siehe {% trans "Sidebar" %} .

{% block sidebar_right %} und {% block sidebar_left %}

Zusätzlich zu dem {% block drawers %} Block gibt es zwei Blöcke für statische Sidebars. Einen für eine Sidebar auf der rechten Seite des Hauptinhalt und einen für eine Sidebar auf der linken Seite. In diesem Fall bekommt der Hauptinhalt etwas weniger Platz und die Sidebar bleibt dauerhaft sichtbar.

{# fmt:off #} {% load insight_tags %} {% block sidebar_left %} {% sidebar sidebar_data=left_sidebar side="left" %} {% endblock sidebar_left %} {% block sidebar_right %} {% sidebar sidebar_data=right_sidebar side="right" %} {% endblock sidebar_right %} {# fmt:on #}
Für weitere Information über die Komponente, siehe {% trans "Sidebar" %} .

content

Dieser Blöcke ist für den Hauptinhalt der Seite vorgesehen. Hier kommt alles rein was rein soll.

Info: {% blocktrans %} Der Block nimmt immer die volle Höhe des Fenstern ein, unabhängig vom Inhalt. Dadurch wird sichergestellt, das sich der Footer nicht mitten im Browserfenster hängt. {% endblocktrans %}

{% block footer %}

Direkt unter dem {% block content %} befindet sich der Footer. Dieser schließt die Seite ab und befindet sich immer am Ende der Seite.

{# fmt:off #} {% load insight_tags %} {% block footer %} {% footer data=footer_data %} {% endblock footer %} {# fmt:on #}
Für weitere Information über die Komponente, siehe {% trans "Footer" %} .

{% block extra_scripts %}

Zuletzt gibt es einen Block um zusätzliche JavaScript Dateien zu verlinken.

{% endblock content %} {% block footer %} {% footer data=footer_data %} {% endblock footer %}
