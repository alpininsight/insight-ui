{% trans "What is Insight UI, just another CSS/JavaScript framework?" %}

{% blocktrans %} Insight UI is indeed a CSS/JavaScript framework dedicated to Django applications. The difference compared to other frameworks, however, is that Insight UI can be used without a solid foundational knowledge of frontend technologies such as HTML, JavaScript, CSS, etc. Insight UI is primarily intended for Rapid Prototyping and designed in such a way that it can be used by developers who have little prior knowledge of or interest in frontend development. For this purpose, our framework provides a set of pre-built components that can be inserted directly into the template and just need to be populated with data. {% endblocktrans %}

{% trans "The components are implemented with accessibility in mind and support, with regard to internationalization, an RTL layout for languages that are read from right to left." %}

{% trans "For good performance, the relevant components support the use of HTMX requests to update only individual parts of the DOM without a full page reload. "%}

{% trans "What is Insight UI not?" %}

{% blocktrans %} Insight UI is neither a CSS library nor a JavaScript library. Insight UI is designed exclusively for Django applications. While our framework offers several, quite flexible customization options, it has primarily been designed with less of a focus on creative freedom. {% endblocktrans %}
